## 🛠 Sobre el Proyecto
Este repositorio centraliza toda la identidad visual de **Baikal Hardware**. Aquí se gestionan los archivos maestros tanto en formato vectorial (SVG) como en mapas de bits (PNG) para asegurar la consistencia en todos nuestros materiales de limpieza técnica y hardware.

## 📂 Estructura del Repositorio

* **/Logos**: Variantes del logo oficial con y sin nombre, incluyendo versiones con fondo transparente.
* **/Carteles**: Diseños para insumos técnicos, como el etiquetado de Alcohol Isopropílico al 99% para limpieza electrónica.

## 🚀 Uso de los Assets
Los archivos están optimizados para:
1.  Impresión de etiquetas de insumos.
2.  Uso en redes sociales y documentación técnica.
3.  Desarrollo de interfaces y branding digital.

## ✒️ Identidad Visual
Nuestra marca se caracteriza por un estilo retro/pixel-art, utilizando una foca como emblema distintivo. Los colores principales se encuentran representados en los archivos `.svg` de este repositorio.
